# 2026 五系聯合迎新宿營網站

這是一個一頁式活動介紹網站，用來呈現 2026 中山五系聯合迎新宿營資訊。

## 內容

- 參與系所
- 活動簡介
- 活動內容
- 三天流程
- 活動地點
- 贊助商與店家資訊
- 聯絡資訊

## GitHub Pages

建議使用 GitHub Pages 從 `main` 分支的根目錄發布。
